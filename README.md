# Hierarchical Bayesian Network Meta-analysis — Antidiabetic drugs & liver outcomes

This repository contains the analysis pipeline used to run a hierarchical Bayesian network meta-analysis
that accounts for clustering of studies within data sources (registries/databases) and for study-level
heterogeneity. The pipeline extracts contrasts from an extraction spreadsheet, runs pairwise REML
meta-analyses, fits a JAGS-based hierarchical NMA (study-level and database-level random effects),
computes SUCRA rankings, and produces league tables and network plots. All effect sizes are modeled on the log-hazard ratio scale assuming approximate normality.

#Repository structure

- `data/`
  - `raw/` 
  - `HEPATIC_T2DM_SYNTHETIC.xlsx` (synthetic example included for transparency)
- `R/`
  - `01_data_cleaning.R` - read raw extraction, normalize registry names, create `.study_id`
  - `02_contrast_extraction.R` - robust extract of HRs, build contrast table with covariates
  - `03_pairwise_meta.R` - run pairwise REML meta-analyses summary
  - `04_jags_nma.R` - prepare JAGS data, run hierarchical NMA and check convergence
  - `05_postprocess.R` - extract posterior draws, build pairwise effect table and SUCRA
  - `06_viz_and_tables.R` - create league tables (gt) and network plot
  - `utils.R` - helper functions used across scripts
- `models/`
  - `nma_hierarchical_db_study.jags` - the JAGS model file (study + database random effects)
- `output/` (generated by scripts)

# How to run

1. Install system dependency: JAGS (>= 4.3). 
2. Clone repo, place your extraction Excel into `data/raw/` (filename described in scripts), or use `data/example_data.csv`.
3. Open R and run the scripts in order 01 -> 06. Each script writes intermediate results to `output/`.
4. Inspect `output/league_table.pdf`, `output/network_chc.pdf`, `output/diagnostics.RDS`.

# Model description

The JAGS model fits a likelihood for each observed contrast taking the reported within-study variance (vi) as known, and models two sources of heterogeneity via random effects: a study-level random effect and a database/registry-level random effect. This structure accounts for clustering of contrasts within studies and clustering of studies within the same registry.

#Mathematically

- Observed contrast: \(y_i \sim N(\theta_i, v_i)\)
- True contrast: \(\theta_i = d_{t1[i]} - d_{t2[i]} + s_{study[i]} + u_{db[i]}\)
- Study-level random effect: \(s_j \sim N(0, \tau_{study}^2)\)
- Database-level random effect: \(u_k \sim N(0, \tau_{db}^2)\)

Where `d[t]` are the basic treatment effects (fixed-effects parameters) and one treatment is chosen as reference.
